# Amethyst SDL shim: Minecraft 26.3 on Amethyst iOS (unofficial, test build)

Minecraft 26.3 switched from GLFW to **SDL3** for its window, keyboard and mouse. Amethyst (iOS) only has
GLFW, so 26.3 crashes at start with `NoClassDefFoundError: org/lwjgl/sdl/SDLPlatform`.

This shim adds the missing parts **without changing the Amethyst app**. You add one custom version file,
and Amethyst downloads a small (~400 KB) Java library that:

- implements the **83 SDL3 functions 26.3 calls**, on top of Amethyst's own GLFW (window, OpenGL context,
  keyboard, mouse, text input, clipboard, display info),
- adds LWJGL's SPIRV-Cross bindings (26.3 converts every shader with them, even on OpenGL; Amethyst already
  ships the native library),
- patches two small things on load: a macOS-only menu call that would crash on iOS, and an image-resize
  function missing from Amethyst's LWJGL (rewritten in Java),
- turns off Vulkan so 26.3 stays on OpenGL.

> **Status: v0.1.0, first test build.** It has **not been tested on an iPad yet.**
> Keyboard and mouse only; touch controls were not tested.
> **Use a separate test world. Do not open your hardcore world with it.**

## What was tested

On Linux, using **Amethyst's own LWJGL Java classes** taken from the IPA (only its iOS GLFW was swapped for
desktop GLFW), Mesa software OpenGL, and real keyboard and mouse input:

| | |
|---|---|
| Title screen, menus, fonts, panorama | ✅ |
| Mouse move and click, scroll wheel | ✅ |
| Typing (world name, chat), Shift, Ctrl+A, Backspace | ✅ |
| Create world, spawn, walk (WASD), mouse-look | ✅ |
| Mouse grab and release (inventory, pause, chat) | ✅ |
| Save and quit, world thumbnail, quit game | ✅ |

Not testable off-device: Amethyst's iOS surface and renderer (ANGLE / MobileGlues), its input bridge, and
whether the renderer accepts the GLSL 330 shaders 26.3 generates.

## Install (on the iPad)

1. **Java 25 must be selected:** Amethyst → Settings → Réglages Java (Java Tweaks) → **Manage runtimes** →
   tap **java-25-openjdk** so it has a checkmark.
2. **Minecraft 26.3 must be installed in Amethyst.** If you already tried launching 26.3, it is.
3. In Safari, download
   [`26.3-sdl-shim.zip`](https://github.com/fxr-lmao/Performance_manus/raw/refs/heads/claude/funny-newton-f07uqe/amethyst-sdl-shim/release/26.3-sdl-shim.zip).
   In the **Files** app, tap it to unzip. You get a folder named `26.3-sdl-shim`.
4. Move that **folder** into **On My iPad → Amethyst → instances → default → versions**.
   Move just this one folder; don't replace the `versions` folder.
5. In Amethyst, create a **new profile**:
   - Version: **26.3-sdl-shim**
   - Game directory: something new, like `26.3-test`, so these test worlds stay away from your other worlds
   - Renderer: leave it on the default first
6. Launch it. Amethyst downloads `sdlshim-0.1.0.jar` automatically, and its checksum is verified.

If it crashes, share `latestlog.txt` (Files → Amethyst). Lines starting with `[SDLShim]` show what the shim
did. This test build also logs every key press; that's intentional for debugging. If the crash is about
shaders or the renderer, try another renderer in the profile (for example MobileGlues).

**Manual jar install (only if the automatic download fails):** download
[`sdlshim-0.1.0.jar`](https://github.com/fxr-lmao/Performance_manus/raw/refs/heads/claude/funny-newton-f07uqe/amethyst-sdl-shim/release/sdlshim-0.1.0.jar)
and put it at `instances/default/libraries/dev/amethyst/sdlshim/0.1.0/sdlshim-0.1.0.jar`.

## Known limits (v0.1.0)

- Vulkan is disabled; 26.3 uses OpenGL.
- No IME composition (preedit). Plain typing works.
- `Open URL` links in menus do nothing.
- Every SDL window maps onto Amethyst's single screen and GL context.
- Audio device change events are reported as unsupported, so 26.3 polls instead. Sound itself is unaffected.

## How it works

| File | Role |
|---|---|
| `src/dev/amethyst/sdlshim/Sdl.java` | SDL3 → GLFW translation: windows, GL context, event queue, keyboard and mouse state, displays |
| `src/org/lwjgl/sdl/*` | The SDL classes 26.3 calls, with signatures identical to LWJGL 3.4.3, delegating to `Sdl` |
| `src/dev/amethyst/sdlshim/Agent.java` | Java agent: the `MacosUtil` no-op and the `NativeImage` resize redirect |
| `src/dev/amethyst/sdlshim/StbResize.java` | Java replacement for `stbir_resize_uint8_linear` |
| `src/dev/amethyst/sdlshim/KeyTables.java` | GLFW key → SDL scancode/keycode tables, generated by `tools/gen_keytables.py` |
| `src/org/lwjgl/openal/SOFTSystemEvents*.java` | Reports ALC system events as unsupported |
| `keep-classes.txt` | The 96 LWJGL 3.4.3 SDL struct classes reused unchanged (checked to link against LWJGL 3.3.3) |
| `release/26.3-sdl-shim/26.3-sdl-shim.json` | The custom version: inherits 26.3, loads the agent, sets the LWJGL library names |

Build: `AMETHYST_LWJGL=/path/to/Payload/AngelAuraAmethyst.app/libs/lwjgl.jar ./build.sh` (JDK 25+), then
`python3 tools/make_release.py 26.3.json release/sdlshim-<ver>.jar <ver>`.
